Every small touch, side by side

Left is what the live site does today, using the real site CSS. Right is the same piece with the lab effects added. Nothing here uses a library. Every effect is CSS plus a few lines of JavaScript, and every one turns off for touch screens and reduced motion.

Page transition

Now: clicking a case study card flashes to a white-then-dark new page. Lab: the old page fades out in 180ms and the new one fades up 8px in 260ms. This is one CSS rule, @view-transition { navigation: auto }, on both pages. Works in Chrome, Edge and Safari 18.2+. Firefox just loads the page as before.

Notes

Libraries, if we want them

Everything above is zero dependencies. Three things are nicer with a library, and they are optional:

Motionmotion.dev, MIT, ~5kb from a CDN. Real springs for the magnetic pull and chip pops, and exit animations (a card that shrinks away). Vanilla JS, no React needed.
Lenis~3kb. Smooth, weighted scrolling. It is the standard on award sites, but it also changes how scrolling feels for everyone, so try it before committing. Live demo · GitHub
GSAPFree since 3.13. Only worth it for pinned, scrubbed, cinematic scroll sections. Overkill for this site today. Showcase · ScrollTrigger demos

Rules used throughout, from animations.dev: under 300ms, ease-out for anything entering, only transform and opacity, press at 97% not smaller, stagger 30–80ms, no motion for touch or reduced-motion users.
